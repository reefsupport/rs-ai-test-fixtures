# rs-ai test fixtures

Public smoke-test fixtures for [rs-ai](https://github.com/reefsupport/rs-ai)
model workers. Public because RunPod Serverless workers need a publicly
fetchable URL during pipeline development.

Source clips are CC-BY-4.0 from EPFL Sauder et al. — see Zenodo record
[10624794](https://zenodo.org/record/10624794).

Attached as release assets (binary blobs don't belong in git):
- `test_5s.mp4` — 5-second trim of the Red Sea GoPro Hero 10 clip used for
  smoke testing the deepreefmap worker.
